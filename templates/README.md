# Local Revenue Coach State

This directory keeps the minimum context needed for coaching continuity. The default `.gitignore` excludes business state because it may contain sensitive commercial information.

- `PROFILE.md`: stable goals, constraints, strengths, and boundaries.
- `STATE.md`: current mode, bottleneck, experiment, and next action.
- `PIPELINE.csv`: a small manual prospect pipeline.
- `LOG.md`: append-only evidence and decision notes.

Use ranges or aliases when practical. Never store passwords, API keys, payment-card details, identity documents, or unnecessary client information here.

Delete fields you do not want to maintain. The framework works without persistent state.
