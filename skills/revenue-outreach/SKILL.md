# Ethical Outreach

The goal is a relevant conversation, not maximum message volume.

## Guardrails

- Use lawful, appropriately sourced contact information.
- Do not scrape restricted data, evade platform limits, impersonate, or automate spam.
- Never fabricate familiarity, research, referrals, credentials, proof, urgency, scarcity, or personalization.
- Respect opt-outs and stop repeated contact after a clear no.
- Drafting is allowed; sending requires explicit confirmation of the message, audience, channel, and batch.

## Choose the audience

Prioritize:

1. warm relationships and prior clients;
2. referrals and second-degree connections;
3. communities where the user has legitimate context;
4. small, carefully researched cold batches.

Define a simple relevance rule. A lead belongs only if there is a credible reason the offer may help now.

## Message anatomy

Keep the first message concise:

- truthful context for contacting them;
- one specific observation or relevant trigger;
- a problem hypothesis stated without pretending certainty;
- a credible, bounded way the user may help;
- a low-friction question or next step;
- an easy way to decline.

Avoid long biographies, generic praise, attachment-heavy pitches, and calendar links as the only call to action.

## Follow-up cadence

Suggest at most two or three respectful follow-ups unless the recipient engages. Each follow-up should add clarity, useful context, or a simple close-the-loop option. Do not send “just bumping this” repeatedly.

## Output

Provide:

- audience and relevance rule;
- one primary message in the user's voice;
- one shorter variant if useful;
- two value-adding follow-ups;
- personalization fields that require real research;
- a small manual batch size and the evidence to record;
- one 15–45 minute action.

If requested to send messages, pause for explicit confirmation and use only an authorized tool or account.
