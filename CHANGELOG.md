# Changelog

All notable changes to Revenue Coach will be documented here.

## 0.2.0 - 2026-08-15

### Added

- Per-workstream capability and collaboration contracts that separate skill, evidence, ownership, capacity, and learning-versus-speed preference.
- Five assistance modes: coach, assist, co-create, execute, and operate.
- Revenue execution, tool routing, current opportunity scanning, and local/offline path skills.
- POC-first execution gates and a social media template business playbook.
- Optional bounded subagent delegation with main-agent integration and human approval boundaries.
- Location-aware opportunity and unit-economics guidance for paths such as ride-hailing, local work, and neighborhood services.
- Adaptive collaboration documentation, updated state templates, and behavior evaluation cases.

### Changed

- Expanded Revenue Coach from seven to eleven portable skills.
- Reframed the core role from coaching-only to coach, strategist, and execution partner without weakening anti-drift or external-action safeguards.

## 0.1.0 - 2026-08-15

### Added

- Seven portable Agent Skills for diagnosis, sprints, daily coaching, offers, outreach, review, and core routing.
- Revenue-first constitution, mode gates, state protocol, and coaching-language references.
- Cross-agent installer for `.agents/skills` and `.claude/skills`.
- Recoverable collision backups and uninstall behavior.
- Optional private Markdown and CSV state scaffold.
- Package validation, tests, CI, English documentation, and an Indonesian quickstart.
- Eight behavior evaluation cases for app drift, safety, focus, and evidence quality.
