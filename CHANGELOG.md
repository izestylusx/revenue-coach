# Changelog

All notable changes to Revenue Coach will be documented here.

## 0.1.0 - 2026-08-15

### Added

- Seven portable Agent Skills for diagnosis, sprints, daily coaching, offers, outreach, review, and core routing.
- Revenue-first constitution, mode gates, state protocol, and coaching-language references.
- Cross-agent installer for `.agents/skills` and `.claude/skills`.
- Recoverable collision backups and uninstall behavior.
- Optional private Markdown and CSV state scaffold.
- Package validation, tests, CI, English documentation, and an Indonesian quickstart.
- Eight behavior evaluation cases for app drift, safety, focus, and evidence quality.
